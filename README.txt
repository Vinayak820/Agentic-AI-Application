# Expense Tracker MCP Server

## About

This is an AI-based expense tracking system.
You can manage your expenses, income, and debts using simple chat messages.

---

## Features

### Expense Management

* Add expense (food, travel, shopping, etc.)
* Edit expense
* Delete expense
* View expenses by date

### Income Tracking

* Add income

### Reports

* Get expense summary
* Check balance (income - expense)
* View top spending category
* Monthly expense graph

### Debt Management

* Borrow money
* Lend money
* Settle debts
* View all debts
* Check pending balance

### Data Control

* Clear all expenses
* Reset database

---

## Extra Tools

### Web Search

* Search anything from internet

### Calculator

* Perform basic math operations

### Stock Price

* Get latest stock price

---

## Example Commands

* Add expense of 500 for food
* I spent 200 on travel

* What is my balance this month
